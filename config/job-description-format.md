# Job description format

Every job (in Recommendations and Jobs) keeps a **Job description** section in its page body, written by the system when the job is found or added. Postings get taken down, and the fit analyzer and CV drafter both rely on it.

It's an **item-by-item paraphrase**, not a verbatim copy: postings are the company's copyrighted text. Reword each item, but keep everything:

- **Every responsibility and every qualification** as its own bullet. Never merge, drop or summarize away an item.
- **The original order and grouping**, under the posting's own section names (e.g. "What you'll do", "What you'll bring", "Nice to have").
- **Must-have vs. nice-to-have labels** exactly as the posting states them. If the posting doesn't separate them, say so.
- **Specifics intact:** numbers, years, tools, languages, certifications, locations.
- **A header line:** title · company · location(s) · work mode · employment type · salary (or "not stated"), plus where the text was read from and when, with the original link.
- **Short company context** at the end, if the posting gives it.

Never add qualifications the posting doesn't state; interpretation belongs in the fit analysis.
